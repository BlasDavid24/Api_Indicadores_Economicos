# Indicadores Económicos de Chile (API)

Aplicación web que consume una API pública para obtener y mostrar indicadores económicos de Chile en tiempo real.

## Descripción
Este proyecto utiliza una API de indicadores económicos para visualizar datos como UF, dólar, euro, entre otros, mostrando información actualizada de forma dinámica en una interfaz web.

Los datos son obtenidos desde servicios como https://mindicador.cl/

---

## Funcionalidades
- Consumo de API mediante solicitudes HTTP (fetch)
- Visualización de indicadores económicos en tiempo real
- Manejo de datos dinámicos en la interfaz
- Actualización de información desde fuente externa

---

## Indicadores utilizados
- UF (Unidad de Fomento)
- Dólar
- Euro
- Bitcoin

---

## 🛠️ Tecnologías utilizadas
- JavaScript
- HTML5
- CSS3
- API REST
